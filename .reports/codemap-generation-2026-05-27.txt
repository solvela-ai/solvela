KEY ARCHITECTURAL DECISIONS DOCUMENTED

1. Gateway is ONLY binary — All other crates are libraries (reusable)
2. x402 has no Axum dependency — Pure protocol library
3. PaymentVerifier is chain-agnostic — Designed for EVM support later
4. Provider adapters translate OpenAI ↔ native format
5. 5% platform fee on all requests
6. Fire-and-forget database writes (tokio::spawn, no .await on hot path)
7. Response cache is wallet-agnostic (shared between agents)
8. Graceful degradation without PostgreSQL or Redis
9. Migration failure is fatal if DATABASE_URL is set
10. API key auth uses Axum extractor pattern (RequireOrg, RequireOrgAdmin)
