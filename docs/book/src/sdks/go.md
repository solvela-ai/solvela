# Go SDK

The Solvela Go SDK is maintained as a standalone module at
[github.com/solvela-ai/solvela-go](https://github.com/solvela-ai/solvela-go).

```bash
go get github.com/solvela-ai/solvela-go
```

See the upstream repository's README for installation, configuration, and
API reference. The other SDK guides in this handbook (Python, MCP Server)
remain in-tree.
